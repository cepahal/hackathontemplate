# 07 — Demo Engineering

## Flow
```text
Start → Problem → User action → Meaningful AI/product behavior → Visible result → Value
```

## Minimize
typing · waiting · setup · flaky external calls · extra navigation · live sign-up

## Techniques
- Pre-login demo account
- Seeded data
- Cached/sample AI output fallback
- One URL deep-link to demo screen
- Presenter checklist card
