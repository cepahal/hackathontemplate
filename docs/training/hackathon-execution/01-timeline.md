# 01 — Hackathon Timelines

## Principle
Reserve **10–15% buffer** at the end for deploy/demo/pitch failures. Never schedule polish into the last minute.

## Phase budget (relative)
| Phase | Share (approx) |
|---|---|
| Discovery + idea lock | 5–10% |
| Architecture lock | 3–5% |
| Core vertical slice | 25–35% |
| MVP completion | 15–20% |
| Integration + testing | 10% |
| UI polish | 8–12% |
| Deployment | 5–8% |
| Demo + pitch prep | 10–15% |
| Buffer | 10–15% |

Exact hour tables: `schedules/12h.md`, `24h.md`, `36h.md`, `48h.md`.

## Rule
If behind at checkpoint → cut P1/P2, not buffer.
