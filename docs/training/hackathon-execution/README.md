# Hackathon Execution — Idea → Pitch

Goal: not merely finish an app. Ship:

```text
working product
+ polished experience
+ reliable demo
+ clear story
+ strong technical explanation
```

under extreme time pressure.

Companion programs:
- Idea quality → `../product-strategy/`
- Build quality → `../../AGENTS.md` + `../web-fundamentals/`
- Break/fix → `../debugging-recovery/`

## The loop you must execute

```text
AMBIGUOUS PROMPT
→ STRONG IDEA
→ SMALL MVP
→ VERTICAL SLICE
→ WORKING PRODUCT
→ TEST
→ POLISH
→ DEPLOY
→ DETERMINISTIC DEMO
→ 2-MINUTE STORY
→ JUDGE Q&A
```

## Non-negotiables

1. First **end-to-end vertical slice** before feature breadth
2. Always keep a **time buffer** before judging
3. **Feature freeze** once core + deploy + demo work
4. Demo has **primary + fallback** for every fragile hop
5. Pitch starts with **WHY**, not the tech stack
