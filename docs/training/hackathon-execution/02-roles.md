# 02 — Team Role Assignment

## Roles (combine as needed)
| Role | Owns |
|---|---|
| Product lead | Scope, story, freeze calls, judge narrative |
| Technical lead | Architecture, integration risk, code review of AI diffs |
| Frontend | UI, states, demo screens |
| Backend | API, authz, DB |
| AI/ML | Model calls, eval harness, fallbacks |
| Integration | Glue, webhooks, third parties |
| UI/UX | Visual system, polish pass |
| Deployment | Env, prod, smoke |
| Demo/pitch | Script, click path, Q&A, backup recording |

## Rules
- Prefer **overlap on the vertical slice** early; parallelize only after E2E works
- One owner per hot file cluster (see team workflow docs)
- Product lead + tech lead may be the same person on teams of 2–3
- Demo presenter should not be deep in infra risk in the final 2 hours
