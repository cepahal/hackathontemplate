# Hackathon Product Strategy — Training Program

Goal: turn an ambiguous hackathon prompt into a **high-quality, feasible, differentiated, demoable** concept in **30–60 minutes**.

Not optimized for random startup ideas. Optimized for:

```text
problem quality
+ user pain
+ AI leverage (non-decorative)
+ technical feasibility
+ differentiation
+ demo quality
+ time feasibility
```

## Instinctive questions (memorize these)

```text
Who has the problem?
Why is it painful?
Why does the current solution fail?
Why is AI useful (not decorative)?
What can we build in 12–24 hours?
What is the smallest compelling product?
What will the judge remember?
```

## Pipeline (timed)

```text
prompt → decode (5–10m)
      → 15–20 ideas (10–15m)
      → 5 serious (10m validation)
      → 2 concepts (MVP + demo)
      → 1 pick (matrix + team fit)
```

## Reject by default

- Generic chatbot / ChatGPT wrapper with no workflow lock-in
- Generic AI dashboard with no proprietary context
- Ideas where AI is a sticker, not a capability
- Ideas that need unavailable data, long ML training, or perfect accuracy

Read `01-decode.md` + `cheatsheets/idea-kill-tests.md`, then run **Speed Drill 01** with your mentor.
