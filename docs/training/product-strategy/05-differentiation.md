# 05 — Differentiation

Ask for every idea:

1. Why not just ChatGPT?
2. Why not the existing product?
3. What proprietary workflow / data / context?
4. What is hard to copy in 48h by another team?
5. What makes the **demo** memorable?

## Moat proxies in a hackathon (honest)
- Workflow lock-in (files, tools, roles)
- Domain constraints / evaluation harness
- Live data integration
- Multimodal capture
- Speed + UX in a specific job-to-be-done

## Avoid
generic chatbot · generic wrapper · generic dashboard — unless workflow/context is real.
