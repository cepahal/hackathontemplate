# 09 — Demo Design

Every serious idea needs:

### 60s
Problem (1 line) → action → magic → result → value

### 2 min
+ one edge / trust moment (citation, undo, audit, before/after)

### 5 min
+ architecture one-liner + what we'd ship next (shows judgment)

## Structure
```text
Problem → Action → AI/product magic → Result → Value
```

Judges remember **one image**: before/after, live capture, or "wrong answer prevented."
