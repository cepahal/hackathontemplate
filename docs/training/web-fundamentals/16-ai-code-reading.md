# 16 — AI Code Reading Protocol

When handed AI code, answer before running:

1. What does it do (one sentence)?
2. What HTTP request is sent/received?
3. What data returns?
4. What can fail?
5. Security problem?
6. What SQL runs?
7. Behavior on 500?
8. Behavior with two simultaneous users?

Then run or read evidence. Mentor critiques.

Practice snippets live in `drills/` and `reference/ai-snippets.md`.
