# UI Review Workflow

## Passes
1. **Demo path** — can a stranger complete the happy path?
2. **States** — loading / error / empty present and readable?
3. **Responsive** — phone width usable for demo screens?
4. **Accessibility** — labels, focus, contrast, keyboard
5. **Polish** — spacing consistency, typography hierarchy, no clipped text
6. **Motion** — helps hierarchy; does not block

## Anti-slop check
Flag generic filler UI that weakens product identity.

## Output
List concrete UI defects with component/route references.
Prompts: `prompts/ui/`
