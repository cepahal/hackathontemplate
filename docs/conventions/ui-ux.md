# UI / UX Conventions

## Hierarchy
- One primary CTA per screen
- Brand/product identity readable in the first viewport for marketing pages
- Dense admin/data UIs may differ — clarity still wins

## States
Ship loading, error, empty for every data-backed view.

## Motion
Use 2–3 intentional motions max on marketing surfaces; none that delay task completion.

## Avoid (generic AI-UI tells)
- Purple-on-white default gradients as the whole identity
- Card grids with no real content
- Pill soup / chip overload
- Decorative gradients pretending to be product imagery

## Accessibility
- Semantic HTML
- Focus visible
- Contrast
- Alt text for meaningful images
