# UI library guide

The current web component guide is [finalfrontentbackend/docs/UI_LIBRARY.md](../finalfrontentbackend/docs/UI_LIBRARY.md).

It covers the canonical Next.js app in `finalfrontentbackend/frontendFINAL/`, the `/ui`, `/ui/workspace`, and `/ui/website` previews, uppercase component APIs, required environment configuration, and browser verification.

The existing Expo/React Native app remains in `mobile/`. See its [README](../mobile/README.md) for separate install, development, and export commands. Native device execution and signing are separate from bundle checks.
